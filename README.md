## Как разместить через GitHub Pages

Загрузите **содержимое архива** в корень репозитория (рядом должны лежать `index.html`, `style.css`, `js.js`, `normalize.css` и `alexander.jpg`). В GitHub: Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
